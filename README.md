# Página Web Efectos CSS



### ¿Para que sirve?
En esta ocasión podemos encontrar un blog sobre **Física** donde se desarrollan temas de interés. Pero eso no es lo importante, el objetivo principal es aplicar efectos y diseño audaz pero moderno, para darle entender al usuario, que el mensaje no solo es lo que *contiene*(Física) si no lo que lo contiene(**diseño** CSS)

> Este Blog fue creado como proyecto escolar

### Tecnologías
* HTML
* CSS
* UX
* Interfaces 
* Carrusel dinámico de imágenes
### Cómo ejecutar
1.-Clona el Repositorio y abre el archivo _index.html_ (dentro de la carpeta **Web_efectos_css** ) en el navegador de tu preferencia
``` bash
git clone https://github.com/SalvadorPy/Web_efectos_css.git
```

### Aprendizajes


* Utilizar display-flex, overflow-x: scroll  y scroll-snap-align para poder darle estructura al carrusel
* Organizar el texto de manera armónica con las imágenes
* Enlazar los enlaces para acceder a partes del blog
* Conocer los parámetros de márgenes en los objetos.
